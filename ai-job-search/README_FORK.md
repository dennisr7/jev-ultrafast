# ai-job-search tools (anonymized copy)

This folder is a copy of the ai-job-search tooling with all personal data removed: profiles, CVs, cover letters,
application trackers, documents and scraped job data are blank templates. Upstream: https://github.com/MadsLorentzen/ai-job-search

The scripts expect the layout `ai-job-search/jev-ultrafast/`. To use them together, treat this folder as the workspace
and clone the Jev repo inside it:

    git clone <this repo> jev-ultrafast

Then fill in `profiles/primary/profile.md` with `/setup` in Claude Code.
