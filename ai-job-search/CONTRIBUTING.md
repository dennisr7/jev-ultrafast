# Contributing

Changes are welcome. Before opening a change:

- Run the checks: `python3 tools/lint_skills.py` and `python3 -m pytest tests`.
- Keep personal data out of commits: profiles, CVs, cover letters, application trackers, documents and scraped job data stay local. `.gitignore` covers the usual paths; check `git status` before you commit.
- Keep market-specific portal skills in your own workspace. The shipped skills and commands should work for anyone.
- Describe what changed and how you checked it.
